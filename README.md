# Портфолио — Лада Назаренко

Лендинг в монохроме и стекле, зелёный акцент. React + Vite.

## Что править

| Файл | Зачем |
| --- | --- |
| `src/data/profile.ts` | Имя, текст «обо мне», навыки, контакты, пункты меню |
| `src/data/projects.ts` | Карточки работ: текст, стек, ссылки, порядок |
| `src/components/portfolio/` | Секции: шапка, первый экран, работы, обо мне, контакты |

Новый контакт — объект в `profile.contacts`. Новая работа — объект в `projects`.

## Локально

```bash
npm install
npm run dev
```

## Деплой

Репозиторий подключён к Vercel. Пуш в `main` собирает сайт заново.
